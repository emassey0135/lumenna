# Lumenna

Lumenna is a task manager and day planner. Tasks go into time blocks for as many sittings as they take, and everything syncs with your other devices that run Lumenna, with no server in between.

Press H-Chord on any Lumenna screen for help about that screen. Press Z-Chord to leave a screen.

## How every screen works

- Enter does the main thing for the item you are on: shows a project's tasks, a task's details, edits a block.
- M-Chord with Dot 7 opens the item's context menu, with everything else that can be done to it.
- M-Chord opens the screen's main menu: adding, moving between days, searching, undo and redo.
- Most commands also have a letter that does the same from the list; the menus say it after each command. The same letter means the same thing everywhere: a adds, u undoes, y redoes.
- A capital letter, the letter with Dot 7, moves to the next item starting with it.
- Control-D or the D chord deletes the item you are on. A deleted task goes to the Trash and can be restored.
- Left and right, or Dot 7-Chord and Dot 8-Chord, fold and unfold an item that has others under it.

## The main menu

- Today, shortcut t: the day's blocks, free time and now. See [Lumenna Day](help:lumenna-day).
- Tasks, shortcut k: every open task. See [Lumenna Tasks](help:lumenna-tasks).
- Add a task, shortcut a: type it the way you would say it, such as "call the bank tomorrow at 3pm p1 #Home".
- Filters and search, Projects, Labels: see [Lumenna Projects, Labels and Filters](help:lumenna-organise).
- Blocks, shortcut b: every block, including ones on no day near today.
- Trash, shortcut x: deleted tasks, to restore or erase for good.
- Undo, shortcut u, and Redo, shortcut y: the last change made on this device, wherever it was made.
- Sync now, shortcut n: one round with your other devices now. See [Lumenna Settings](help:lumenna-settings).
- Settings, shortcut s: see [Lumenna Settings](help:lumenna-settings).
