# Lumenna Projects, Labels and Filters

## Projects

The project tree, with each project's open tasks, its weight and whether it is archived. Enter shows a project's tasks. Its context menu, M-Chord with Dot 7:

- Add a task to it, t. Add a project inside it, n. Rename, r. Move it under another project, m.
- Move up, comma, and Move down, period.
- Weight, w: how much the whole project matters now, roughly 0.5 to 2, or "inherit".
- Archive or Unarchive. Delete, which asks whether its tasks go to the Trash or to the Inbox.

The main menu, M-Chord, has Add a project, a.

## Labels

Enter shows the tasks wearing a label. Its context menu: Add a task wearing it, t. Rename, r. Merge it into another label, m, for a near-duplicate made by a typo. Colour, c: a colour name, or none; the name always shows too. Move up and Move down. Delete, which leaves the tasks as they are. The main menu has Add a label, a.

## Saved filters

Enter opens a filter's tasks. A filter is kept as you typed it, so "today" means today whenever it is opened. Its context menu: Rename, r. Change the query, q. Move up and Move down. Delete. The main menu has Add a filter, a, and Search or filter now, slash.
